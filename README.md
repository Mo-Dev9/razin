# رزين (Razin)

دليل أسعار الإيجار الحقيقية لكل حي في مصر، من إعلانات السوق العامة فقط — مع مجتمع «حارة» لملاحظات السكان ونصائح الحي.

> قبل الإيداع، خذ رأي الحي، خذ رأي رزين.

## ما يقدمه

- متوسطات أسعار الإيجار لكل حي من إعلانات السوق النشطة (وسيط + نطاق، مع تنبيه «بيانات محدودة» لقلة العينات).
- حاسبة سعر تقديرية تبحث بأقرب عينات متاحة من بيانات الحي.
- خريطة المباني وبياناتها وتقييماتها.
- مجتمع «حارة»: ملاحظات قريبة حول الحي بشكل مجهول، مع تصويت وتعليقات وإبلاغ.

## الأساسات

- Next.js (Turbopack) + React 19 + TypeScript + Tailwind v4 + pnpm.
- Firebase (Firestore + Admin SDK) — القواعد تُنشر بـ `firebase deploy --only firestore:rules`.
- Sentry مفعّل؛ اختبارات Vitest (`pnpm test`).

## الأوامر

```bash
pnpm dev       # التطوير على :3000
pnpm test      # اختبارات Vitest
pnpm lint      # ESLint
pnpm build     # إنتاج + فحص الأنواع
```

## التنظيم

- `src/app/` — الصفحات وواجهات API (`/api/admin/*`, `/api/posts/*`, `/api/visit`…).
- `src/lib/` — منطق الأعمال الخالص: الأسعار، الزاحف، الجدول الجغرافي، الجلسات، معدّلات الحدود.
- `src/types/index.ts` — نماذج البيانات.
- `firestore.rules` — قراءة عامة، كتابة عبر الخادم فقط.
